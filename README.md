# AI 头脑风暴 · 课程作业版

让一个 AI 同时扮演五个角色，按头脑风暴的流程陪你做完一份课程作业。

不是程序，不需要安装，不用 API key。复制一段文字，粘进任何能对话的 AI，就能开始。

---

## 它解决什么问题

直接问 AI「帮我做个关于短视频的作业」，你会得到一堆正确但没用的话：要明确研究问题、要注意方法、要参考文献。这些话你自己也知道。

问题不在 AI 不够聪明，在于**没有一个能质疑你的角色**。真实的头脑风暴之所以有效，是因为有一个人专门唱反调，有一个人专门记，有一个人专门控时间。一个人跟 AI 聊天，这三样全缺。

这个工具包把这三样补上：五个角色由同一个 AI 扮演，靠规则约束各自的边界。

## 五个角色

| 角色 | 干什么 | 不许干什么 |
|---|---|---|
| 引导者兼时间官 | 控流程、控时长、跑偏时拉回 | 不许出主意，单次发言不超 80 字 |
| 记录员 | 给想法编号、贴标签、整理成表 | 不许评价、不许新增、不许润色 |
| 发散者 A · 稳妥派 | 给有依据的、能落地的方向 | 不许没依据就说「我觉得」 |
| 发散者 B · 跳脱派 | 给想不到的角度、类比、反转 | 不许自我否定 |
| 挑战者 | 扮演最挑剔的评分老师 | 不许给解决方案，只开火 |

用户自己兼任发散者和最终决策者。

## 六个阶段

```
澄清 8 分钟 → 纯发散 12 → 生长发散 12 → 挑战 12 → 收敛 10 → 落成 8
```

其中三步需要你实质参与：回答澄清问题、出几个想法、做最终选择。其余三步说「继续」就行。

两条硬规则：

- **发散阶段禁止评价**（一说「但是」想法就死了）
- **挑战阶段禁止新增想法**（不然被质疑时就靠「换个想法」逃避）

## 三十秒开始

1. 打开 [`prompts/one-click.txt`](prompts/one-click.txt)，全选复制
2. 粘进任意 AI 对话框，发送
3. 照它的提问回答。**每条回复的最后一行会写「轮到你」或「还没到你」**，后面跟着一句你能直接打出去的话

不用记流程，也不用想下一步该说什么——最后那一行就是给你的提示。

```
→ 轮到你：回答第 1 个问题｜直接回：一句话答，答不上来就回「不知道」
→ 轮到你：是否进入挑战｜直接回：继续
→ 还没到你：发散B 接着出 5 条（不用回）
```

如果那一行没出现，说明模型漏了规则，发一句「铁律第 8 条」。实在懒得想，回「然后呢」，它会给你两个选项。

## 两种使用方式

**普通用户**：复制 `prompts/one-click.txt`，粘贴即用。任何模型都行，手机上也行。

**AI 工具用户**：把整个文件夹放进 skills 目录，AI 会在你说「帮我头脑风暴」「选题想不出来」时自动加载 `SKILL.md`。

- WorkBuddy：`~/.workbuddy/skills/`
- Claude Code：`~/.claude/skills/`

## 设计上做了什么

一模型演五个角色，最大的失败是五个声音变成一个。这个包里三处是刻意这么写的：

**每张角色卡都有「你不做什么」。** 模型天生倾向于帮忙，让它当主持人它会忍不住出主意，让它当挑战者它会忍不住给方案。禁止清单比形容词有效得多。

**给每个角色配了「语料特征」。** 只说「你是严谨的学者」没用，要说「常用词：依据、文献、把握度；不说：我感觉」。语气差异靠词汇，不靠人设。

**给发散者 B 配了类比清单。** 游戏、综艺、体检、外卖、剧本杀。不给具体燃料的「跳脱派」，只会说「换个角度想想」。

## 已知局限

- **发散者 A 给的「依据」可能是编的。** 模型被要求给文献时会硬编。凡是要写进作业的，自己核一遍。
- **四十分钟后角色会趋同。** 引导者和记录员容易混成一个「协调者」。这是一模型多角色的天花板，缓解办法是拆成两次做。
- **没有跨会话记忆。** 今天的讨论明天接不上，得把一页纸纪要贴回去。
- **时长是估的。** 62 分钟未经实测，可能 40 分钟走完，也可能 90 分钟装不下。
